# 项目状态与复现说明

[English overview](../README.md) | [中文介绍](../README_zh-CN.md)

本页说明当前公开仓库的资源范围和复现条件。文件名沿用原有路径，以保持链接兼容。

## 已提供的内容

- 三维标注重投影、SHP→ISAT→COCO 转换、SHP 直接转 COCO，以及影像和标签裁切工具。
- MMDetection 3.2.0 下四个监督模型的配置、训练与测试入口。
- 大图切片推理、边缘实例合并、结果汇总、GeoJSON 导出和实例结果像素级评估。
- 基于 SAM 3 官方实现的文本提示 zero-shot 推理与评估。提示词固定为 `solar panel`，通过 10 张训练影像初步比较选定，不训练或微调模型。
- 使用说明、第三方许可证、文件来源与校验清单。

代码默认值为作者实际采用的基准参数，详见[评估说明](BENCHMARK.md)。公开仓库仅包含项目工具与配置，完整框架需单独安装。

## 评估与复现边界

当前配置使用 12 座宁波电站训练，使用 `test-crop/013` 验证，部分模型按验证集 `segm_mAP` 选择最佳权重。013 同时属于计划中的宁波测试集，因此最终实验的验证及权重选择流程仍需核对，不能将当前配置视为独立验证划分的证明。

MMDetection 与 SAM 3 的框架内部修改尚未对照实际训练环境完成核查。框架来源、模型权重、环境版本及完整运行参数共同决定复现条件；仅安装同名框架不保证结果完全一致。

`provenance/validation.json` 区分当前检查与历史检查。语法、配置加载、命令行和合成数据检查不等于完整 GPU 训练或城市级推理复现。

## 使用时需要注意

- 模型权重需自行准备；SAM 3 权重按官方获取流程及许可使用。
- 示例相机内参仅展示命令格式，必须替换为实际去畸变影像对应的参数。
- 单图 GeoJSON 工具与主评估工具默认 NMS 类型不同，比较时应统一。
- 更改数据、权重、提示词或后处理参数后使用新的输出目录，避免缓存混用。
- 报告实验时记录实际配置、命令行覆盖参数及代码提交版本；汇总评估使用完整且参数一致的电站结果。
